## Premise under test

Issue Blakeolson21/no-slop#7 ("Move the non-convergence round cap inside the
gate") demanded, on breach of a non-convergence threshold: (1) a configurable
threshold evaluated by the executor; (2) **terminate the run with a distinct
outcome (e.g. `parked-nonconverging`)** rather than another fix round; (3) the
accumulated findings in a pasteable form; (4) never require a human decision to
stop a diverging loop.

## Finding: premise refuted in part — no distinct terminal state exists or is needed

The current main already satisfies demand (1) and supersedes demands (2) and (4)
with a deliberately advisory, parked-gate design. A `parked-nonconverging`
terminal state was **deliberately not built**; the parked state reuses existing
fields and is documented as such. Adding a distinct terminal outcome now would
duplicate an outcome the design explicitly rejects.

Source basis (all at `26065f4`):

- `internal/convergence/convergence.go:12-16` — "The guard is advisory by
  design: a tripped report never aborts a run. It stops the pipeline from
  spending further automatic fix rounds and parks the gate for an explicit
  decision ... and the operator can still respond fix deliberately."
- `internal/pipeline/executor.go:1125-1132` — report rebuilt and persisted
  after every review round; a tripped guard is advisory, "never aborts the run
  and never blocks an explicit approve, skip, or fix response".
- `internal/pipeline/executor.go:1144` — tripped guard stops `auto_fix.review`
  funding; `internal/pipeline/executor.go:1189-1198` — a tripped guard with
  actionable findings is forced into the park path so the loop cannot end as
  "passed" carrying the flagged findings.
- `internal/cli/axi_drive.go:483-490` — `--yes` hands the tripped gate back as
  an explicit decision point ("gate parked by the convergence guard");
  `axi_drive.go:549-556` — the guard outranks the per-step fix budget
  (`maxYesFixRoundsPerStep = 3`, `axi_drive.go:530`).
- `internal/config/config.go:273-279` — configurable thresholds
  (`review.convergence.non_decreasing_rounds`, `recurring_rounds`, budget),
  defaults 3/3/120min; documented in
  `docs/src/content/docs/reference/repo-config.md:375-396`, which states a
  tripped guard "is **advisory**: it never aborts the run".
- The findings the gate carries are the ticket-ready seed: the gate doc renders
  the findings plus the full convergence history (round counts, review time,
  findings outside the submitted diff, recurring classes) —
  `internal/cli/axi_render.go:gateFields`, pinned by
  `internal/cli/axi_convergence_test.go:TestGateRendersConvergenceHistory`.
- Demand (4) ("never require a human decision") is intentionally **not**
  satisfied: the design parks for an explicit decision (same citations). That
  is a documented owner-facing design decision postdating the issue, not a
  missing implementation to invent here.

## What was added: one compatibility test across the four surfaces

No product code changed. A new focused test pins that the actual parked
non-converging state — review step at `fix_review` with a tripped
`convergence_json`, run `running` + `awaiting_agent_since` set, **no terminal
state** — is coherent across every surface:

- `internal/cli/axi_parked_nonconverging_test.go` (new)
  - `TestStatusRendersParkedNonconvergingAsAwaitingAgent` (line ~76): one
    `axi status --run` read shows `awaiting_agent: parked`, the tripped
    convergence warning, and **no top-level `outcome:` field**.
  - `TestParkedNonconvergingSurvivesReopenAndReplay` (line ~123): the parked
    state survives close/reopen (status still `running`,
    `awaiting_agent_since` intact, tripped report intact), and a head-change
    replay reset (`ResetStepsFromOrder`, `internal/db/step.go:306-327`)
    preserves the review's tripped report while invalidating later steps.
  - `TestRenderDriveResult_ParkedNonconvergingExitsZeroWithGateDoc` (line
    ~190): a drive that stops at the tripped gate **exits 0** with the gate
    doc (convergence block, "Do not respond `fix` by default"), never a
    passed/failed outcome. Exit-0-on-decision-gates is a documented contract
    (`internal/cli/axi_test.go:TestSkillExitCodeGuidanceDistinguishesDecisionGates`).
- `internal/tui/parked_nonconverging_test.go` (new)
  - `TestParkedNonconvergingReviewRendersAsPausedGate`: the TUI renders the
    parked review as the paused gate `⏸ Review` and never as a terminal
    `✓ Completed` / `✗ Failed` / `✗ Cancelled` banner, even though the step
    carries the tripped report.

## Observed, not acted on

TUI yolo mode (`internal/tui/commands.go:91-114`) funds exactly one fix round
on a tripped gate and then approves the re-entered `fix_review` gate. This is
consistent with the documented yolo contract — "an explicit override ...
consent to run one fix round" (`docs/src/content/docs/concepts/auto-fix.md:73`)
— and the approval itself is an explicit human pre-authorization the daemon
accepts by design. It is an asymmetry versus `--yes` (which never funds a
tripped gate), recorded here as an observation, not fixed, because changing
yolo's documented contract is a product decision outside this lane's scope.
